# GPIO Basics

This directory contains introductory Raspberry Pi GPIO programming examples written in C using the libgpiod library.

## Programs

1. `gpio_led_on.c` – Turn an LED ON.
2. `gpio_led_off.c` – Turn an LED OFF.
3. `gpio_led_blink.c` – Blink an LED.
4. `gpio_read_input.c` – Read an external digital input.

## Environment

- Hardware: Raspberry Pi 4 Model B
- Operating System: Raspberry Pi OS (64-bit)
- Programming Language: C
- GPIO Library: libgpiod
